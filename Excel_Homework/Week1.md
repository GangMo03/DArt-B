## 1. 참조 방식
엑셀의 참조 방식은 `$` 기호를 활용하여 셀의 행과 열을 고정할지 결정하는 방식이다. 수식을 다른 셀로 변환할 때 어떤 부분을 고정하고 어떤 부분을 변경할지 지정할 수 있다.

* **상대 참조**: `$` 기호를 사용하지 않는 방식 (예: `A1`)
  * 수식을 다른 셀로 복사하면 행과 열이 함께 변경됨
* **혼합 참조**: 행 또는 열 중 하나만 `$` 기호를 사용하여 고정하는 방식 (예: `$A1`, `A$1`)
  * 열 또는 행 중 하나만 고정됨
* **절대 참조**: 행과 열 모두 `$` 기호를 사용하여 고정하는 방식 (예: `$A$1`)
  * 수식을 다른 셀로 복사해도 행과 열이 변경되지 않음

## 3. 표와 데이터의 구분 및 올바른 데이터 관리
표와 데이터를 명백하게 구분해서 관리해야 한다.

* **데이터**: 실제로 관리하고 분석해야 하는 원본 정보
* **표**: 데이터를 보기 좋게 정리하고 시각화한 형태 중 하나

단순히 표 형태로만 데이터를 관리하면 다음과 같은 문제가 발생할 수 있다.
* 데이터를 정렬하거나 찾을 때 어려움이 발생할 수 있음
* 새로운 데이터가 계속 추가될 경우 관리가 어려워질 수 있음
* 데이터의 형태가 변경되면 기존 표의 구조를 수정해야 할 수 있음
* 함수나 피벗 테이블을 활용하기 어려워질 수 있음

따라서 새로운 데이터가 지속적으로 쌓이고 데이터의 형태가 변경되는 상황에서도 쉽게 관리할 수 있도록 **데이터를 올바른 구조로 관리**해야 한다. 단순한 표 형태에 의존하기보다 함수와 피벗 테이블 등의 엑셀 기능을 적절하게 활용하는 것이 중요하다.

## 4. 셀 병합 기능 사용 시 주의점
셀 병합은 보기에는 편리하지만, 엑셀의 데이터 관리 및 분석 기능을 제한할 수 있으므로 주의해서 사용해야 한다.

셀을 병합하면 다음과 같은 문제가 발생할 수 있다.
* 데이터의 값이 원하는 방식으로 표시되지 않을 수 있음
* 표 기능이나 피벗 테이블 사용에 제약이 생길 수 있음
* 데이터 정렬 기능을 정상적으로 사용하기 어려울 수 있음
* 데이터 범위의 수정 및 편집이 제한될 수 있음
* 함수나 데이터 분석 기능을 활용하는 데 불편함이 발생할 수 있음

따라서 단순히 보기 좋은 형태로 만들기 위해 데이터를 관리하는 영역에서 **셀 병합을 사용하는 것은 가급적 피하는 것**이 좋다. 데이터는 병합하지 않고 행과 열을 일정한 규칙으로 유지해야 엑셀의 다양한 기능을 제대로 활용할 수 있다.
