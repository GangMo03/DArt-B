## 1. 맷플롯립 API 간략하게 살펴보기

### 개념정리

Matplotlib은 파이썬의 대표적인 데이터 시각화 라이브러리로, MATLAB 스타일의 API를 제공한다.
크게 두 가지 방식으로 사용할 수 있다.

- pyplot 방식 (상태 기반): `plt.plot()`, `plt.show()` 처럼 간단하게 호출하는 방식. 빠른 시각화에 적합하다.
- 객체지향 방식: `fig, ax = plt.subplots()`로 Figure와 Axes 객체를 직접 다루는 방식. 세밀한 제어가 필요할 때 권장된다.

주요 구성 요소:
- Figure: 전체 그림 영역 (캔버스)
- Axes: 실제 그래프가 그려지는 영역 (subplot 하나하나)
- Axis: x축, y축 등 개별 축
- 자주 쓰는 함수: `plot()`, `scatter()`, `bar()`, `hist()`, `xlabel()`, `ylabel()`, `title()`, `legend()`

## 4. 그룹 연산에 대한 고찰

### 개념정리

판다스의 그룹 연산은 분리(Split) → 적용(Apply) → 병합(Combine) 패턴을 따른다.

핵심 개념:
- `groupby()`는 즉시 연산하지 않고 GroupBy 객체를 반환한다 (지연 연산)
- 하나의 컬럼뿐 아니라 여러 컬럼을 리스트로 전달해 다중 그룹화도 가능하다
- `groupby` 키로 사용된 컬럼은 자동으로 인덱스가 되며, `as_index=False`로 방지할 수 있다
- 인덱스 기준으로 그룹화하려면 `level` 파라미터를 사용한다

```python
df.groupby(["컬럼A", "컬럼B"]).mean()
df.groupby("컬럼A", as_index=False).sum()
```

## 6. apply 메서드: 일반적인 분리-적용-병합 

### 개념정리

`apply()`는 GroupBy에서 기본 집계 함수로 표현하기 어려운 임의의 함수를 그룹별로 적용할 때 사용한다.

df.groupby("키").apply(사용자_정의_함수)

특징:
- 함수의 반환값에 따라 결과 형태가 달라진다
  - 스칼라 반환 → 집계 결과 (Series)
  - Series 반환 → DataFrame
  - DataFrame 반환 → 계층적 인덱스를 가진 DataFrame
- `group_keys=False` 옵션으로 그룹 키가 인덱스에 추가되는 것을 방지할 수 있다
- Series에 대해서도 동일하게 `apply()` 사용 가능

내장 집계 함수로 해결되면 `apply()` 보다 빠르므로, 꼭 필요한 경우에만 사용하는 것이 좋다.

## 7. 그룹 변환과 래핑되지 않은 groupby

### 개념정리

**transform()**: 집계와 달리 원본 DataFrame과 **동일한 크기의 결과**를 반환한다.
그룹별 통계값을 원래 행에 브로드캐스트해서 붙여줄 때 유용하다.

```python
# 그룹 평균을 원본 행에 붙이기
df["그룹평균"] = df.groupby("키")["값"].transform("mean")

# 그룹 내 정규화
df["정규화"] = df.groupby("키")["값"].transform(lambda x: (x - x.mean()) / x.std())
```

**래핑되지 않은 groupby (filter)**:
`filter()`는 조건을 만족하는 **그룹 전체**를 남기거나 제거한다.

```python
# 그룹 크기가 3 이상인 그룹만 남기기
df.groupby("키").filter(lambda x: len(x) >= 3)
```

- `transform` → 행 수 유지, 값 변환
- `filter` → 조건 불만족 그룹 제거
- `apply` → 유연한 변환/집계 (형태 자유)

## 8. 피벗 테이블과 교차표 

### 개념정리

**피벗 테이블**: 데이터를 행/열 기준으로 재구성하여 그룹별 집계를 2차원으로 표현한다.

```python
df.pivot_table(values="값", index="행기준", columns="열기준", aggfunc="mean", fill_value=0)
```

주요 파라미터:
- `values`: 집계할 컬럼
- `index`: 행 방향 그룹 기준
- `columns`: 열 방향 그룹 기준
- `aggfunc`: 집계 함수 (기본값 `mean`), 리스트로 여러 개 지정 가능
- `margins=True`: 행/열 합계(소계)를 함께 표시
- `fill_value`: 결측값 대체값

**교차표 (crosstab)**: 두 범주형 변수의 빈도를 집계하는 피벗 테이블의 특수한 형태.

```python
pd.crosstab(df["컬럼A"], df["컬럼B"], normalize=True)  # 비율로 표시
```

피벗 테이블은 `groupby + unstack()`으로도 동일한 결과를 만들 수 있다.
